🔍 Search Widget Live Demo

This is a mock customer website to demonstrate how the Search Widget looks and feels. Look at the bottom-right corner of your screen! A floating search button has been injected.

How to embed it on any site:

Just copy and paste this code right before the closing </body> tag of your HTML:

<!-- 1. Add the widget container with your Project ID --> <div id="saas-search-widget" data-project-id="76b6ee77-dd54-473b-96d7-c2b300b2fc9c"></div> <!-- 2. Load the widget script --> <script src="http://localhost:3001/widget.js" defer></script>

Note: Since this is a test file, you need to replace `YOUR_PROJECT_ID` below with an actual Project ID from your database to see real search results.
